# AT Statistic Downloader

**1.0.0-beta** — неофициальное расширение Chrome для экспорта статистики Author.Today в Excel и JSON.

## Возможности

- Добавляет кнопку **«Скачать статистику»** к каждой книге в списке редактирования произведений.
- Автоматически определяет имя пользователя из адреса страницы и ID книги из её карточки.
- Получает общую статистику, просмотры по главам и время чтения за выбранный период.
- Сохраняет **Excel (.xlsx)**, **JSON** или оба файла из одних ответов сервера.
- Объединяет ранее сохранённые JSON в общий Excel или единую JSON-коллекцию.
- Показывает ход загрузки, предупреждения и ошибки отдельных запросов.

## Установка

Требуется Chrome 120 или новее.

1. Скачайте [установочный ZIP 1.0.0-beta](dist/AT-Statistic-Downloader-1.0.0-beta.zip)
   и распакуйте его в постоянную папку. Если скачали исходники репозитория,
   рабочие файлы расширения находятся в папке `extension`.
2. Откройте `chrome://extensions` и включите «Режим разработчика».
3. Нажмите «Загрузить распакованное расширение» и выберите папку с `manifest.json`.
4. Войдите в Author.Today и откройте список редактирования своих произведений:
   `https://author.today/u/USERNAME/works/edit`.
5. Если страница уже была открыта, полностью перезагрузите её.

Для обновления замените файлы в прежней папке, обновите расширение на
`chrome://extensions`, затем перезагрузите страницу Author.Today.

## Выгрузка книги

Нажмите «Скачать статистику», укажите даты и формат, затем нажмите «Скачать».
Оба выбранных дня включаются полностью по московскому времени (UTC+3).
По умолчанию предлагаются последние семь дней и формат Excel.
Выбранные даты и формат запоминаются до перезагрузки страницы.

Для запросов используется текущая авторизация в браузере. Запросы выполняются
последовательно, в том числе при выборе нескольких книг. В режиме двух
форматов Chrome может запросить разрешение на несколько скачиваний.

## Форматы

**Excel** содержит четыре листа:

| Лист | Содержимое |
| --- | --- |
| Общая статистика | Даты, просмотры, уникальные просмотры, время, комментарии, лайки, изменение библиотек |
| Просмотры глав | Главы, даты или метки периодов, просмотры |
| Время чтения | Главы, даты или метки периодов, значения времени |
| Сведения | Источники, выбранные периоды, результаты запросов, предупреждения и ошибки |

В таблицах есть фильтры и закреплённые заголовки. Даты и показатели имеют
соответствующие типы ячеек. Нули, `null`, отсутствующие значения и отрицательные
числа различаются. Время сохраняется в единицах API без пересчёта.

**JSON** сохраняет исходные ответы сервера вместе с ID книги, периодом,
именем пользователя и результатами запросов. Формат подходит для дальнейшей
обработки и повторного импорта в расширение.

Если удалось получить только часть статистики, файл помечается `_partial`.
При полном отказе скачивания нет: причина показывается рядом с кнопкой.

## Объединение JSON

Закрепите иконку расширения на панели Chrome и нажмите её. Выберите сохранённые
JSON-файлы, формат результата и нажмите «Объединить и скачать».

Обработка выполняется локально и не требует входа в AT. Отчёты разных книг
и периодов сохраняются отдельными снимками. Столбец «Снимок» в Excel связывает
данные с их источниками; в общем JSON исходные отчёты находятся в массиве
`reports`. Пересекающиеся периоды не суммируются и не перезаписываются.

Ограничения импорта: до **100 отчётов** и **20 МБ** файлов за один раз.
Один Excel ограничен **500 000 ячеек**. Для большего объёма используйте JSON
или разделите выгрузку на меньшие периоды.

## Диагностика

В окне выгрузки можно раскрыть «Диагностика запросов» и проверить `auId`.
Проверка сравнивает ответы с пустым параметром и без него, выполняя шесть
последовательных запросов. Для сравнения выбирайте завершившийся период.
Результат применяется только к совпавшим ответам этой книги и периода
до перезагрузки страницы.

## Приватность и ограничения

Расширение не запрашивает пароль, не передаёт выгрузки разработчику и не
использует собственные серверы или внешние библиотеки. Новая статистика
читается только с Author.Today; импортированные JSON обрабатываются на устройстве.
Перед передачей выгрузки другим людям учитывайте, что она содержит имя
пользователя и статистику произведений.

Расширение видит книги, уже загруженные на текущей странице. Автоматического
обхода страниц, фонового опроса и повторов запросов нет. При HTTP 401, 403
или 429 оставшиеся запросы книги останавливаются.

Это независимый проект, не связанный с администрацией Author.Today.
Условия AT ограничивают сторонние скрипты; согласование на автоматизированный
сбор пока не получено. Перед использованием учитывайте
[соглашение](https://author.today/pages/terms) и [оферту AT](https://author.today/pages/offer).
